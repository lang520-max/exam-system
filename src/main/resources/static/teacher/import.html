导入试卷

把符合模板格式的 JSON 导进来：题目可以随卷新建，也可以按 questionId 引用题库里已有的题。导入的试卷一律是草稿， 学生看不见，确认无误后到「考试管理」点「发布」。

返回考试管理

1 · 目标题库

选中某个题库就导进它；保持默认则看 JSON：给了 bankId 用它， 只给了 bank.name 就按名字找，找不到会新建。

2 · JSON 内容

把 .json 文件拖到这里 或点击选择文件；也可以直接把 JSON 粘贴到下面的输入框

3 · 导入前预览

预览只做本地结构性检查（题数、题型分布、分值合计）；完整校验在后端执行， 任何一题不合法都会返回带题号的问题清单，并且整批都不会入库。
